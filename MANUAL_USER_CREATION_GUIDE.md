# Manual User Creation Guide

Open `Admin Panel -> People & accounts`, then click `Add person`.

The form supports:

- Student accounts with department, programme, section, student ID, admission year, and roll number.
- Staff/admin accounts with employee ID, department, designation, roles, and scopes.
- Administrative accounts with roles and explicit access scopes.
- Account status selection during creation.
- Secure temporary password generation and reveal/hide control.

Use `Add another after saving` when entering several users manually. The saved user list refreshes, the modal remains open, and a fresh temporary password is generated for the next account.

New users are created with `mustChangePassword = true`. The temporary password is shown only in the form or reset result and must be shared through a trusted channel.

The user list can be filtered by search text, role, account status, and first-login state. The table displays department, section, first-login status, account status, and last sign-in so admins can spot incomplete onboarding quickly.
