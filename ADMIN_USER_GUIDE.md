# Administrator Guide

Use **People & accounts** to create an identity, temporary password, one or more roles, and explicit access scopes. Users must replace temporary passwords. Suspend/disable users to revoke sessions. Configure active campus locations, issue categories/common problems, responsible teams, routing rules and SLA policies before opening issue reporting. Use **Bulk imports** for preview-confirm onboarding; download the current template and inspect every row result.

Review unassigned/overdue issues, notification failures, reported-message moderation, audit logs, integration status and backups daily through **Audit & operations**. Retry only understood failures and record moderation notes. Never share seeded credentials or provider secrets. Cancel/reject issues only with a recorded reason. Scope every export to the authenticated administrator's authorized area.
